# 遭遇随机化 —— 交接文档

> 用途：把"普通遭遇敌人随机化 + 强度对齐"这件事的**全部已知事实与已验证结论**固化下来，供新会话直接接手。
> 工作目录：`D:\ps2\DDSAT2-rand-dsh`　原始 ISO：`DDSAGA2.iso`（SLPM-65795，中文补丁版）
>
> **本文档只保留已验证成立的内容。** 被推翻的假设、失败的实验、错误方向一律不写进来，
> 以免后来者（人或 AI）被误导。方法论见 `docs/METHOD_ENEMY_SWAP.md`。

## 一、需求（用户口径）

1. **普通遭遇敌人任意 1:1 随机互换**（不做等级限制）；
2. **互换后，该位置的敌人必须变成"被它替换掉的那个敌人"的**：
   - 等级、HP 上限/当前、MP 上限/当前、**五项能力**、**技能列表**；
   - 即：**保留该刷怪点原有的强度**，只是外形/名字换了；
3. **不能改 HP 的敌人（特殊单位、Boss 专属）不要放进随机池**；
4. **地图只应出现它本来会出现的敌人等级段**（例：占拠された地下街 按 wiki 只会出现 LV3–8）；
5. 有些敌人**不适合作野生敌人**（废案、会变身的人类兵），需要**用户可配置的 ban 列表**：
   - 被 ban 的敌人要**移出随机池**，并且它占的遭遇位置要换成**同场景的其他遭遇**；
6. （另有独立 bug）**敌人战斗出招仍是自己的 AI**，需要连 AI 招式表一起换 → 见 `docs/FINDINGS.md` 与 AICALC.TBL。

## 二、ENCOUNT.TBL（已验证）

### 2.1 文件分节

ELF 里的文件描述符在 `0x286328`，格式是每节 8 字节 `[u32 size][u32 ptr]`，
第一项是路径指针。六节 size 依次为：

```
0xa000(40960)  0x3040(12352)  0xaf00(44800)  0x80(128)  0x3040(12352)  0x700(1792)
```

**权威布局**：

| 文件偏移 | 内容 | 大小 |
|---|---|---|
| `0x0000` | 头（u32 = `0x0000a000`，其余 0） | 16 |
| `0x0010` | **表1**：1024 条 × 40 字节（遭遇组） | 40960 |
| `0xa010` | 表2 头 = `40 30 00 00 15 00 00 00 00 00 00 00 07 08 00 00` | 16 |
| `0xa020` | **表2**：1029 条 × 12 字节 | 12348 |
| `0xd060` | **表3** ~44800 字节（**含敌人编号，尚未解**） | |
| `0x17f80` | 表4 头 | 12 |
| `0x17f8c` | **表4**：1029 条 × 12 字节 | 12348 |
| `0x1af98` | **表5** 1792 字节 | |

### 2.2 表1 记录格式（**这是唯一与敌人替换相关的表**）

```
+0 .. +9    其它字段（未知）
+10 +12 +14 +16 +18    u16 × 5   ← 敌人编号（0 = 空槽）
+36          u16 标记（块内多为 0x0100，后段 0x0000）
```

- 记录 `r` 的文件范围 = `0x10 + 40r .. +40`；
- **同一敌人按数量 1/2/3/4 连续占若干条记录**，块结构清晰。
  例（占拠された地下街）：`8..11` = アルプ 1~4 只、`22..24` = タラスク 1~3 只、
  `15..16` = 75 一头/两头、`19` = `[76,75,76]`、`51` = `[41,40,41]`（第一场 Boss）……

**已验证的表1 记录块（供"同场景替换"使用）**：

```
rec  2..4   96      5..7   60      8..11  76(1~4只)   15..16 75
rec 17 [96,77]     18 [75,60]     19 [76,75,76]
rec 22..24 41      25..27 40      28..32 59      33..35 74   36..39 93
rec 40..41 58      42..43 92      44..47 94      48 [59,93,59]
rec 49 [41,73]     50 [93,40]     51 [41,40,41]  52 [58,92]
rec 53..55 73      56 [74,40]     57..59 71      60..62 30   63..65 32
rec 66 56          67..68 57      69..71 72      72..73 70   74 39
```

### 2.3 ⚠️ 编号 → UNIT.TBL 记录的映射是 **`记录 = 编号 + 127`**

**这一条极其重要，曾经用错成 `+128` 导致整体错位一条记录。**

- 证据（游戏内实测）：把所有遭遇记录改成编号 **37**，战斗面板显示
  **LV52 / HP600 / MP368** —— 正好是 `UNIT.TBL` 记录 **164** = `37 + 127`。
- 因此：
  - `UNIT_BASE = 127`（`src/ddstool/unitmap.py`）
  - 遭遇重调目标/来源：`rec = 127 + id`（`src/ddstool/randomizer.py`）
  - Boss 重调：`eid + 127`

### 2.4 表2 / 表4（**不参与敌人替换**）

字段是 `[u16 a][u16 0][u16 b][u16 0][u16 c][u16 0]`；`b` 是"遭遇组序号"计数器，
其余只有 `0xFFFF` / `0` / 小整数。它们在 ISO 与所有存档之间**逐字节一致**，
不含敌人编号，因此随机化**不需要也不应该动它们**。

## 三、UNIT.TBL（已验证）

- 结构：**16 字节头 + 896 记录 × 76 字节**；
- 记录内偏移：

| 偏移 | 含义 |
|---|---|
| +0..+9 | 技能（5 × u16） |
| +12/+14/+16/+18 | 不是 HP/MP（未知字段） |
| +52 | u8 模型/类型 |
| **+53** | **等级** |
| **+54 / +56** | **HP 上限 / 当前** |
| **+58 / +60** | **MP 上限 / 当前** |
| **+64..+68** | **五项能力（力/魔/体/速/运）**，上限 99 |
| +69 | u8 种类 |
| +72 / +74 | 技能（2 × u16） |

- 占位/特殊单位：HP = 32767，能力 = `28,28,28,23,14`。**这类不要动**。
- 存档 RAM 里的 UNIT 表副本在 `0x101B81C`（= 记录 128 起，`+76*i`），
  但**战斗单位结构**另存于 `0x101C000`–`0x1022000`，按 76 字节步进，
  其结构 = UNIT 记录 `+52..+76` 的逐字节拷贝。

## 四、当前实现（`src/ddstool/randomizer.py`）

`_randomize_encounters()`：

1. **池** = 所有被"非剧情遭遇记录"引用过的敌人，且 `0 < HP < 10000`（排除占位/特殊），
   且排除"只出现在剧情战阵容里"的敌人，且 **排除用户 ban 列表里的编号**；
2. 池内做**随机双射**（1:1 置换，无自映射）；
3. 重写所有非剧情记录的编号；**被 ban 的敌人占的整条遭遇记录，改写成同块的其它遭遇**；
4. 对每个 target：`set_hp / set_mp / set_level / set_stats / set_skills` 全部对齐 source
   （source = 它替掉的那个敌人的**原始**数值，取自 boot 时快照）；
5. 执行顺序：**Boss 洗牌 →（最后）遭遇随机化**，保证遭遇对齐是最终值。

统计（v16，`--only encounters`，seed 20240911）：

```
172 candidate enemies (172 normal); 27 story battle records
encounter pool: 163 (of 172 normal, 0 story-shared)
encounter enemies swapped 1:1: 939 slot(s), pool=163, retuned=163
```

### 游戏启动/按键（人工已验证）
```
跳 OP(START ×2, 间隔 4s) → 标题 → START 进主菜单 → [2 秒内] N6 进 LOAD
→ N6 选中高亮存档 → W 把光标移到「是」 → N6 读档(等 25s)
→ N6 推进 → N5 取消终端提示 → WASD 走动遇敌
```
按键：`WASD` 方向；**小键盘 6 = ○（确认）**；**小键盘 5 = ×（取消）**；大键盘 `2` = START。

### 构建命令
```
python dds2_randomizer.py --iso DDSAGA2.iso --out DDS2_random_vN.iso --seed 20240911
python selftest.py
```
