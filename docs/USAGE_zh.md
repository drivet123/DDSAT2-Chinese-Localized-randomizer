# 使用说明 (中文)

## 1. 环境

* Python 3.7+（工具本体只用标准库）
* 图形界面需要 PySide2

## 2. 图形界面

```
python dds2_randomizer_gui.py
```

## 3. 命令行

```bash
# 全部随机化
python dds2_randomizer.py --iso DDSAGA2.iso --out DDS2_random.iso --seed 1234

# 分层单独测试（推荐先分别验证）
python dds2_randomizer.py --only encounters --seed 42
python dds2_randomizer.py --only bosses    --seed 42
python dds2_randomizer.py --only text      --seed 42

# 更保守（强度更贴近原版）
python dds2_randomizer.py --variety 0.2 --tolerance 0.15 --seed 7
```

## 4. 规则说明

### 普通遭遇（随机遭遇）
* “普通敌人” = 在遭遇表里出现**不止一次**的 id（会反复出现在随机遭遇里）。
* 换成另一个同样反复出现的 id，要求它的模型文件存在、HP 与属性总和落在
  原值 ±tolerance 内。技能组随单位一起换。
* 含剧情战斗敌人的遭遇记录**完全不改**，保证剧情战阵容不被普通随机污染。

### BOSS / 剧情战斗
* 剧情战斗直接从**战斗事件脚本**里读出来：每个 `/event/**/*.be` 文件在头部
  偏移 `0x50` 存着它的遭遇记录编号，并在 `eNNN_<编号>.BED` 资源名里重复一次。
  这些编号就是剧情战斗（例如 **51 号 = 第一场 BOSS `[41,40,41]`，两个安德拉斯
  加一个ヴェータラ**）。
* 把这些记录的**敌人组合互相调换**（保持原本的敌人数量），模型/动作/技能/AI
  都由 id 决定，始终一致，不会错位。
* 调换后，凡是出现在剧情战斗里的敌人，都会把自己的 HP 与属性总和重设成
  “原本这个位置敌人”的平均值，保证难度相当。战斗脚本与 AI 一律不动。

### 台词 / 语音
* CG 字幕：`/event/**/*.PM1`，在**同一个 CG 文件内部**打乱；
* 游戏内对话：`/fld/**/*.bf`、`/event/**/*.bf`，在**同一个文件内部**打乱；
* 系统文本：`/battle/MSG.TBL`、`/facility/msg/**`、`*.bmd` —— **完全不动**；
* 条目格式是 `名字[16] 保留[8] 行数 标志 语音偏移[] 长度 文本 填充`。一个文件
  内语音偏移正好按条目大小递增，说明语音是**该文件内部**按条目顺序排列的流。
  因此做法是：**保留名字，交换条目正文**（行数/标志/语音偏移/长度/文本/填充）。
  这样字幕会换、语音跟着字幕走（绑定），名字、偏移、文件大小都不变，不会错位。
* 名称像 `TAKARA_GET`、`GET_ITEM`、`*_SEL`、`*_MENU`、`DOOR`、`BATTLE` 等系统
  提示的条目会被排除，不参与打乱。

## 5. 自检

```
python selftest.py
```

## 6. 注意事项

* 输入 ISO 永远不被修改；所有改动文件保持原字节数。
* 如果输出文件被其它程序占用，工具会**直接报错**而不是偷偷写到另一个文件名，
  以免你测试到旧文件。
* 敌人 AI（AICALC.TBL）与等级字段仍未解析，AI 保持原样（符合 BOSS 不动 AI 的
  要求），强度等价由 HP + 属性总和保证。
* 语音只在同一条 CG / 同一个场景内互换，因此跨场景的字幕不会出现“外地语音”
  导致的卡死。
